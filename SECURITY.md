# Security policy

## Supported versions

Security fixes are applied to the latest PaneWeaver release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could affect user data or system integrity. Use GitHub's private vulnerability reporting for this repository when available.

Include the affected PaneWeaver version, Windows build, reproduction steps, and the expected impact. Reports will be acknowledged as soon as practical.

PaneWeaver should never require administrator privileges, transmit user data, modify protected system files, or weaken Windows security controls. Any behavior contradicting those guarantees should be treated as security-sensitive.
